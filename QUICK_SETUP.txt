🚀 5-MINUTE SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Create Google Sheet
   → Go to: sheets.google.com
   → Click: Blank spreadsheet
   → Copy Sheet ID from URL

STEP 2: Setup Apps Script
   → Extensions → Apps Script
   → Copy code from: google-apps-script.js
   → Paste and Save

STEP 3: Deploy
   → Deploy → New deployment
   → Type: Web app
   → Execute as: Me
   → Who has access: Anyone
   → Copy Web App URL

STEP 4: Configure App
   → Open index.html
   → Click: ⚙️ Setup Google Sheets Sync
   → Enter: Sheet ID and Web App URL
   → Save

🔧 TROUBLESHOOTING

❌ Data not syncing?
   → Press F12 (browser console)
   → Check for error messages
   → Verify Web App URL is correct
   → Note: Data still saved locally

❌ Permission error?
   → Re-authorize Apps Script
   → Check "Who has access: Anyone"

❌ Script not working?
   → Make sure you copied ENTIRE script
   → Try re-deploying with new version
